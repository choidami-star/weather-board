# 현장 일정 날씨판

오늘 현장 일정과 Open-Meteo의 지역별 예보를 보고, 판단을 색상 배지로 표시합니다. 일정·담당자는 가상 데이터이며 판단은 교육용 가상 기준입니다.

## 여는 법
- 내 PC : `index.html` 더블클릭
- 인터넷 : (배포 후 Vercel 주소를 여기에 적기)

## 판단 배지
- 초록: 정상 진행. 실내 일정은 날씨와 관계없이 정상 진행
- 노랑: 강풍 주의 (야외·고소, 풍속 10m/s 이상)
- 빨강: 우천 대비 필요 (야외·고소, 강수확률 60% 이상). 강풍과 겹치면 우천 우선
- 회색: 날씨 확인 전 (데이터 없음 또는 불완전)

## 실제 날씨 API
키 없이 [Open-Meteo](https://open-meteo.com/)의 오늘 예보를 받습니다. 인터넷 연결이 필요하며 index.html을 더블클릭해서 사용할 수 있습니다. 요청 형식은 [공식 문서](https://open-meteo.com/en/docs)를 따릅니다.

- `logic.js`: 네 지역 대표 좌표, `buildWeatherUrl()` 주소 생성, `parseWeatherResponse()` 응답 해석, `judge()` 판단. 화면 접근과 네트워크 호출 없음.
- `app.js`: 지역별 API 호출(10초 제한), 실패 처리, 목록과 배지 갱신.
- 요청: `daily=temperature_2m_max,wind_speed_10m_max,precipitation_probability_max`, `wind_speed_unit=ms`, `timezone=Asia/Seoul`, `forecast_days=1`.
- 해석 결과: `{ tempMax, windMax, rainProb }`. 오늘 날짜·수치·단위를 검증하며 누락/오류는 `null`로 처리합니다. 한 지역이 실패해도 다른 지역 데이터와 일정 목록은 유지됩니다.
- `index.html?test=wind`로 열면 정상 수신한 풍속만 12m/s로 바꿉니다. 강수확률은 그대로이며 우천 우선 규칙을 유지합니다. API 실패를 가상 수치로 대체하지 않습니다.
