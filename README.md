# 현장 일정 날씨판

가상 일정과 기상청 단기예보를 보고 판단을 색상 배지로 표시합니다. 판단은 교육용 가상 기준입니다.

## Vercel 설정
1. GitHub의 weather-board 저장소를 Vercel 프로젝트에 연결합니다.
2. Framework Preset은 Other, 루트는 저장소 루트로 설정합니다. 빌드 명령과 별도 출력 폴더는 필요 없습니다.
3. Settings → Environment Variables에 `KMA_SERVICE_KEY`를 추가합니다. 공공데이터포털에서 발급받은 일반 인증키(Decoding)를 입력합니다. Production과 필요한 Preview/Development 환경을 선택합니다.
4. 환경 변수 추가 후 다시 배포(Redeploy)합니다. 이미 채팅에 노출한 키 대신 재발급한 키를 사용하세요.
5. 배포 주소를 열어 지역별 날씨를 확인합니다. 기상청 단기예보 조회서비스 활용 승인이 필요합니다.

실제 인증키는 GitHub, HTML, 브라우저 JavaScript에 넣지 않습니다. `.env.example`은 빈 변수 이름만 제공합니다. 서버 응답에도 인증키나 기상청의 원본 오류를 포함하지 않습니다.

## 로컬 실행
- `index.html` 더블클릭: 일정 보기·추가·저장 가능. 기상청 날씨는 서버 실행 안내를 표시합니다.
- 실제 날씨 포함: Vercel CLI를 준비한 후 프로젝트 루트에서 `vercel link`, `vercel env pull .env.local`, `vercel dev`를 실행하고 표시된 localhost 주소를 엽니다. 환경 변수는 Development에도 설정해야 합니다.
- `.env.local`은 Git에서 제외됩니다. 다른 출처(file/localhost/배포 주소)의 브라우저 저장 일정은 각각 관리됩니다.

## 파일과 API 흐름
- `index.html`, `style.css`: 화면과 모바일 카드 디자인
- `logic.js`: 대표 격자 좌표, 기상청 URL 생성, 응답 해석, 판단 규칙. 네트워크와 화면 접근 없음
- `api/weather.js`: Vercel Node.js Function. 서버 환경 변수로 기상청 API 호출, 입력 검증과 오류 처리
- `app.js`: `/api/weather?region=세종` 등 호출, 표 갱신과 일정 추가
- `PRD.md`, `CLAUDE.md`: 요구사항과 작업 규칙

오늘 전체 시간대를 포함하는 전날 23시 발표의 `getVilageFcst`를 요청합니다. 한국 날짜의 TMX(일 최고기온), WSD(시간별 풍속, m/s), POP(시간별 강수확률, %)를 해석합니다. WSD·POP의 오늘 00~23시가 모두 있어야 최댓값을 계산합니다. 최신 발표의 남은 시간대 최댓값으로 하루 전체를 대체하지 않습니다. 서버 요청은 8초, 브라우저 요청은 10초 제한입니다. 예보는 Vercel CDN에 최대 10분 캐시됩니다.

출처: [기상청 단기예보 조회서비스](https://www.data.go.kr/data/15084084/openapi.do).

## 판단과 확인 방법
- 초록: 정상 진행. 실내는 날씨와 관계없이 정상 진행
- 노랑: 야외·고소 풍속 10m/s 이상
- 빨강: 야외·고소 강수확률 60% 이상. 강풍과 겹치면 우천 우선
- 회색: 날씨 없음 또는 불완전

- T-01: index.html을 열면 기본 일정 6건이 보입니다.
- T-02: 가상 일정을 추가하고 새로고침해도 남는지 확인합니다.
- T-03: Vercel 실행 주소에서 네 지역의 오늘 예보 수치와 판단을 확인합니다.
- T-04: 주소 끝에 `?test=wind`를 붙이면 정상 수신한 풍속만 12m/s가 됩니다. 우천 우선·실내 정상 규칙은 유지합니다.
- T-05: 제목 아래 2026-10-27 표시를 확인합니다.
- T-06: 폭 700px 이하에서 카드와 입력 폼을 확인합니다.
- T-07: API 실패 또는 키 미설정 시에도 일정과 추가 기능이 유지되고, 야외·고소는 회색인지 확인합니다.
- T-08: 배포 페이지의 소스와 `/api/weather?region=세종` 응답에 인증키가 없는지 확인합니다.
