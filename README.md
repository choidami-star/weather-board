## 판단 배지
- 초록: 정상 진행. 실내 일정은 날씨와 관계없이 정상 진행
- 노랑: 강풍 주의 (야외·고소, 풍속 10m/s 이상)
- 빨강: 우천 대비 필요 (야외·고소, 강수확률 60% 이상). 강풍과 겹치면 우천 우선
- 회색: 날씨 확인 전 (데이터 없음 또는 불완전)

## 가상 날씨와 실제 데이터 연결
`app.js`의 비동기 `getWeatherByRegion()`이 가상 데이터를 공급합니다. 실제 API 연결 시 이 함수가 `{ 지역: { tempMax, windMax, rainProb } | null }` 형식으로 반환하도록 교체합니다. 단위는 섭씨, m/s, %이며 숫자로 전달합니다. 비밀 키가 필요한 API는 별도 서버에서 호출해야 합니다.
